# 线上实时房间链接 PvP 设计规范（Phase 5 升级版）

> 本文档固化经用户对齐确认的线上实时联机 PvP 规格，排期调整为 **Phase 4A（标准包 27 将）完成后立即落地**，使好友可携带经典标准武将直接通过房间链接开黑。

## 1. 部署架构（单进程前后端一体）

* **同源托管**：`packages/server`（Node.js + `ws` + 原生 HTTP/静态文件服务）直接托管 `packages/web/dist` 构建产物，并在同一端口暴露 `/ws` WebSocket 端点与 `/health` 健康检查，彻底消除 CORS 与双域配置问题。
* **一键上线模板**：提供根目录 `Dockerfile`、`render.yaml`、`railway.json` 与 `fly.toml`，部署后即得单一公网 HTTPS/WSS 域名，直接分发 `?room=XXXXXX` 房间链接给好友即可开玩。

## 2. 零门槛进房与断线重连

* **免注册流程**：房主建房后生成 6 位大写字母数字房间码与完整邀请链接（`https://<host>/?room=XXXXXX`），支持一键复制。
* **匿名令牌重连**：好友打开邀请链接输入昵称即可入座；浏览器在 `localStorage` 中保存服务端颁发的匿名 `playerToken`（绑定 `roomCode + seatIndex`）。误刷新、手机切屏或网络闪断后重新打开页面即自动携带 `playerToken` 无感重连回原座位。

## 3. 房间生命周期与房主权限

1. **准备大厅**：
   * 房主可配置模式（1v1 / 2v2 / 五人身份场）、牌堆（108 / 161）、武将包范围、自由点将开关、倒计时开关与秒数。
   * 好友通过链接入座后可切换空位并点击「准备」。
   * **房主专属控制**：随时向空位添加/移除 AI 机器人、踢出未开局玩家、移交房主权限；当所有真人已准备且所有座位由真人或 AI 填满后即可开局。
2. **对局中掉线与接管**：
   * 真人掉线后，座位标记为「断线重连中」，保留 **30 秒重连宽限期**（若开启倒计时则超时按服务端默认托管结算）。
   * 宽限期满或房主主动点击「切换 AI 托管」后，由服务端规则 AI 接管该席位继续推进对局，防止卡死。
   * 原玩家随时可通过相同浏览器重新连入并立即夺回该座位控制权。

## 4. 权威防作弊与观战席

* **严格视角隔离**：`GameEngine` 实例仅运行于服务端内存。每次状态变化时，服务端为每个连接独立调用 `buildClientView(state, viewerId, { revealAllHands: false })`，绝不向客户端下发敌方手牌、未亮身份或牌堆顺序（联机房间强制禁用调试明牌，2v2 仅向队友下发手牌）。
* **观战席**：房间座位已满时，额外通过邀请链接访问的好友自动进入观战席（`viewerId = '__spectator__'`），仅接收公开桌面状态、装备、判定区、出牌区与战局日志，无法看到任何玩家手牌或暗置身份。

## 5. 线上实时对局体验

* **服务端权威计时器**：倒计时完全由服务端驱动并广播剩余秒数（防客户端篡改）。房主可在对局中**随时开关倒计时并调整每步秒数（10/15/20/30s）**，改动实时同步全员；超时由服务端自动提交安全默认响应。
* **轻互动聊天**：提供可折叠房间聊天栏 + 常用快捷短语（`救救我`、`别无懈`、`快点吧`、`打得好`、`留桃`），支持观战席与座位玩家交流（对局中不泄露私密牌面）。
* **轮次提醒**：轮到自己出牌或响应时，自动触发浏览器标签页标题闪烁提示与柔和 Web Audio 提示音（可静音）。
* **无懈可击节奏**：采用节奏优先策略，仅向持有【无懈可击】的角色弹出响应，并保留「本回合不再询问同类锦囊」快捷开关。

## 6. 启动与一键公网部署指南

### 本地单进程联机运行
```bash
pnpm install
pnpm build
pnpm server:start
# 默认监听 http://0.0.0.0:3000 （静态网页 + /ws 联机 + /health 健康检查）
```

### 一键公网部署（获得公网 HTTPS/WSS 链接与好友开黑）
* **Render**：仓库根目录已内置 `render.yaml` + `Dockerfile`，在 Render 控制台选择 New Blueprint 关联本仓库即可自动部署。
* **Railway**：已内置 `railway.json` + `Dockerfile`，在 Railway 选择 Deploy from GitHub Repo 即可自动构建并暴露公网域名。
* **Fly.io**：已内置 `fly.toml` + `Dockerfile`，运行 `fly launch --no-deploy && fly deploy` 即可上线。
* **Docker 自建**：`docker build -t sanguosha-minimal . && docker run -p 3000:3000 sanguosha-minimal`
